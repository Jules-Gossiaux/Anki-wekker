# Anki-wekker

Réveil Android personnel qui reste actif jusqu'à la fin des cartes dues sélectionnées dans AnkiDroid.

Le projet est Android-first, local-only et destiné en premier lieu à un OnePlus 10 Pro sous OxygenOS 16. AnkiDroid reste la source de vérité pour les cartes et leur planification.

## État du projet

Le projet commence par une spike d'intégration AnkiDroid et de fiabilité des alarmes Android. La documentation décrit le comportement visé et les limites connues ; elle ne prétend pas encore que ces comportements sont implémentés.
